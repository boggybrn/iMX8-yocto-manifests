# iMX8-yocto-manifests
Use this to initialise a Yocto project for a SolidRun i.MX8 board, with a custom meta-boggybrn layer

```repo init -u https://github.com/boggybrn/iMX8-yocto-manifests -b main -m default.xml```

Then follow instructions as per https://github.com/SolidRun/meta-solidrun-arm-imx8/tree/kirkstone-imx8m
